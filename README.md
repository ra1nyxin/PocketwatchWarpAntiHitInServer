# 血刻表 / Bloodbound Watch

## 中文

这是饥荒联机版的全客户端必装模组。旺达可以在角色制作栏直接制作血刻表，无需工作站：5 纯粹恐惧、2 暗影碎布、1 红宝石、1 时间碎片和 2 金块。

血刻表可手动倒走。携带于物品栏或装备的背包时，它还会在受到攻击或黑暗攻击时自动倒走并避开该次攻击。它使用旺达原版历史节点和倒走距离，每次成功使用后的冷却时间与原版倒走表一致。没有节点或表处于冷却时，攻击照常生效。骑乘及无法中断的状态下不会自动触发。中暑、寒冷和饥饿等直接扣血不会触发自动倒走。

服务器和所有客户端均需启用此模组。

## English

This Don't Starve Together mod adds the Bloodbound Watch for Wanda. Craft it in her character tab without a station using 5 Pure Horror, 2 Voidcloth, 1 Red Gem, 1 Time Piece, and 2 Gold Nuggets. The in-game name is always Chinese: 血刻表.

Use the watch manually to backstep, or carry it in the inventory or an equipped backpack to automatically evade attacks, including Charlie's attack. It uses Wanda's original position history, age-dependent distance, and original Backstep Watch cooldown. Attacks land normally when the watch is cooling down or no history remains. Auto-backstep does not trigger while riding or in uninterruptible states. Direct damage from overheating, cold, or starvation does not trigger it.

The server and all clients must enable the mod.
